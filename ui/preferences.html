How much each shortcut or stepper button changes the correction.

Used only to estimate the tilt angle shown next to each value. Most portable projectors are between 1.0 and 1.5. Check your projector's specifications for the exact number.

The correction runs as an FFmpeg filter, which cannot read frames that stay in GPU memory. When enabled, Keystone switches hwdec to auto-copy while a correction is applied and restores your setting afterwards. Disable only if you manage decoding yourself.
